# Manual de la persona participante

## 1. Elegir una categoría

En la portada selecciona una de las cuatro categorías. Lee las bases, requisitos
y avisos antes de iniciar. Las fechas, datos de contacto y cualquier texto
marcado como pendiente todavía requieren confirmación institucional.

## 2. Crear el registro

Captura el correo, la CURP y los datos de la persona responsable. En Joven
Talento se registra una sola persona participante con un folio individual.
Acepta el aviso de privacidad vigente.

Al crear el registro:

- Se genera un folio único.
- Se abre un borrador editable.
- Se envía un correo de confirmación con el folio.
- No se envía un código temporal en este momento.

Una CURP o un correo ya registrados no pueden utilizarse en otra categoría.

## 3. Completar el borrador

Mientras el estado sea `borrador` puedes guardar cambios, cargar o reemplazar
documentos y elegir entre archivo MP4 o enlace HTTPS para el video. No uses
ambas opciones al mismo tiempo.

Los documentos permitidos son PDF, JPG y JPEG; el video cargado debe ser MP4.
Cada archivo admite hasta 500 MB. Conserva el folio y revisa el resumen antes de
enviar.

## 4. Enviar definitivamente

El resumen muestra la información capturada. Para enviar debes aceptar las
declaraciones vigentes y confirmar que entiendes el bloqueo.

Después del envío:

- El estado cambia a `enviada`.
- Ya no puedes modificar datos o archivos.
- Recibes una confirmación por correo.

## 5. Consultar la solicitud

En “Consulta tu folio” captura correo y folio y solicita el código. La respuesta
es deliberadamente genérica.

El código:

- Tiene seis dígitos.
- Vence en 10 minutos.
- Permite máximo cinco intentos.
- Puede reenviarse después de 60 segundos.
- Solo puede usarse una vez.

La sesión temporal permite consultar únicamente la solicitud asociada.

## 6. Corregir un documento

Si administración marca la solicitud como `incompleta`, verás el comentario y
un solo documento habilitado. Puedes reemplazar exclusivamente ese archivo.
Al confirmar:

- Se conserva la versión anterior para auditoría.
- La nueva versión vuelve a quedar bloqueada.
- La solicitud regresa a `enviada`.
- Recibes una confirmación por correo.

## 7. Cancelar

La cancelación está disponible únicamente en `borrador`, `enviada` o
`incompleta`. Debes confirmar la operación y escribir el folio. Es irreversible
y no elimina el historial.

## 8. Seguridad

No compartas el código temporal. La plataforma nunca solicita una contraseña
permanente para participantes. Los documentos son privados y no tienen URL
pública.
